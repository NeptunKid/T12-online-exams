# PDF 题库 OCR 审阅稿

日期：2026-08-09

本目录是两组扫描试卷的 Tesseract 原始识别稿，只用于人工复核，尚未转换为正式题库，也未写入 PostgreSQL。

## 文件

- `legal-raw.txt`：`《餐饮相关法律法规》` 3 份 PDF、18 页的逐页 OCR 合并稿。
- `coffee-raw.txt`：`《咖啡基础知识 《世界咖啡地图》》` 3 份 PDF、20 页的逐页 OCR 合并稿。
- `review-issues.md`：已发现的题号、字符、选项和答案标记风险。

## 审阅规则

1. 先以 PDF 页面为准核对题干、选项、正确答案和分值；OCR 文本不能作为唯一依据。
2. 绿色“正确答案”标记对应标准答案；若 OCR 把标记识别成 `Ema`、`EMER`、`EER` 等，必须回看原图确认。
3. 题号不连续、选项缺失、图片题、填空题和人工问答题统一标记为待确认。
4. 审阅完成后才生成 CSV 预览；CSV 通过校验后才允许进入后续管理员确认写入步骤。
