# 2026-08-27 外部备份存储契约

## 目标

在不购买云服务、不创建 Bucket、不改生产配置的前提下，为未来 OSS/S3/R2 适配建立统一接口，避免业务层绑定某一家 SDK。

## 本轮实现

- 新增 `src/backup/object-storage.js`：提供受控对象键、原子式“禁止覆盖”语义、MIME/文件名元数据、大小和 SHA-256 记录，以及读取时的完整性校验。
- 新增内存对象存储模拟器，模拟 `putObject`、`getObject`、`deleteObject` 和对象不存在/重复写入错误。
- 未来云厂商 SDK 只需包装为三个方法；凭证仍只能通过部署环境提供。
- 当前自动备份数据库迁移和生产 `storage_type` 仍未接入 `object`，避免在未批准费用和恢复方案前改变生产数据模型。

## 验证

- 新增对象存储测试覆盖：键路径穿越、重复写入、正文大小/SHA-256 校验、删除幂等、客户端契约。
- 未访问网络、未安装云 SDK、未创建云资源、无数据库迁移、无生产写入。

## 下一步

确认 OSS/S3/R2 供应商、区域、私有 Bucket、生命周期和预算后，再单独实现云适配器和隔离恢复演练；未完成演练前不启用生产自动备份。
