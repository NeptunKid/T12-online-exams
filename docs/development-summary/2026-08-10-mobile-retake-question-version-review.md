# 移动端工作台、补考提示与题库版本阅卷

日期：2026-08-10

分支：`feature/legal-cleaning-question-repair`

## 本次范围

- 调整考生移动端顶部栏，确保标题、钉钉账号、刷新和退出登录在窄屏下保持可读、可操作的布局。
- 明确首次考核、一次免费补考和每次额外补考的文案，并在 PostgreSQL 交卷事务中消耗额外补考授权。
- 题库修改后，阅卷页继续默认使用交卷快照，同时显示当前题库差异并允许管理员逐题选择采用当前版本重新阅卷。

## 实现与兼容性

- 工作台账号与操作按钮拆分为独立容器；小于 820px 时标题区自适应、账号右对齐截断，刷新和退出登录固定为同一行。
- 补考文案统一为“第 1 次考核，仅有一次补考机会”“补考”“第 X 次额外补考”。第三次及之后的 PostgreSQL 交卷会锁定并扣减一份额外补考授权，授权不足时事务回滚。
- 已提交答卷始终读取 `submission_questions.snapshot_json`，题库编辑不会覆盖历史题目、作答或分数。
- 阅卷读取当前题库并比较题干、选项、图片、标准答案、解析、分值和题型；管理员可见修改或删除提示。选用当前版本时，客观题按当前标准答案自动重算，问答题保留人工评分；本次依据会保存在 `scores_json.reviewReferences`。

## 数据库与回滚

本次不新增迁移，不修改历史答卷快照。回滚时部署上一版代码并重启 `t12-exams.service`；已保存的重新阅卷依据会保留在答卷评分 JSON 中，如需恢复，应在管理员后台再次按交卷快照保存阅卷结果。
