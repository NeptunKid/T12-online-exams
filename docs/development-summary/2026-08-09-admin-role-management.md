# 开发总结：管理员权限管理

日期：2026-08-09

## 范围

- 钉钉登录时将用户登记或关联到 PostgreSQL，并保留历史答卷用户关联。
- 使用既有 `roles`、`user_roles` 和 `audit_logs` 实现管理员授权与撤销。
- 管理员后台增加用户检索、设为管理员和移除管理员操作。
- 保留 `DINGTALK_GRADER_UNION_IDS` 作为首位管理员的安全引导入口。

## 安全边界

- 普通用户和普通阅卷人不能管理管理员。
- 管理员不能移除自己的权限，也不能移除最后一名系统管理员。
- 钉钉 `unionId` 在管理员列表中遮蔽显示；真实身份和凭证不进入 Git。
- 权限变更写入 `audit_logs`，不修改历史答卷。

## 验证与回滚

- `npm run check`：与最新 `main` 合并后通过，42 项测试、语法检查和敏感信息扫描均通过。
- 回滚只需恢复本次代码提交并重启 Node 服务；本功能不新增迁移，已写入的角色和审计记录可保留，不影响答卷读取。
