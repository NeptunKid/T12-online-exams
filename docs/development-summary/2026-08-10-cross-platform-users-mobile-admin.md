# 跨平台用户与管理员移动端

日期：2026-08-10

## 本次范围

- 钉钉登录优先使用真实姓名；OAuth 仅返回 `nick` 时，通过企业通讯录用户接口补取真实姓名。
- 飞书登录要求 `user_info.data.name`，不使用昵称或英文昵称作为自动合并依据。
- 新身份只在标准化真实姓名唯一匹配一个跨平台用户时自动绑定；同名候选超过一个会拒绝绑定并回滚。
- 新增 `0006_cross_platform_exam_assignments`，为已开放考试建立 `all-active-users` 组授权；旧 `all-active-dingtalk-users` 语义保持不变。
- 题库导入脚本新增 `--all-active-users`，支持钉钉、飞书和历史身份。
- 新增 `scripts/reconcile-cross-platform-users.js`：默认 dry-run，显式 `--apply` 才归并已有重复身份。
- 管理员后台默认显示待批阅；手机端选择答卷后隐藏列表，仅显示当前详情，并提供返回列表按钮；顶栏四个操作按钮在窄屏固定四列对齐。

## 数据安全

- 历史 `submission_questions.snapshot_json`、答卷分数和成绩状态不会被身份归并改写。
- 合并只更新内部 `user_id`、身份、角色、个人授权、补考权限和关联外键；合并后的 `attempt_no` 按提交时间重新编号，避免后续补考次数错误。
- 自动绑定和手工整理均写入 `audit_logs`；同名歧义不会猜测。
- 生产执行 `0006` 或 `--apply` 前必须先用 `pg_dump -Fc` 备份；身份合并没有独立 down migration，撤销只能恢复该备份。

## 回滚

- 代码问题：部署上一份已验证提交并重启 `t12-exams`。
- 仅撤销 0006 组授权：在确认没有后续迁移且已备份后执行标准迁移回滚。
- 撤销身份合并：停止服务并恢复本次 PostgreSQL `pg_dump -Fc` 备份；不要直接删除用户或编辑历史答卷。
