# Phase 1：002 历史答卷导入对账

日期：2026-08-07

## 任务与范围

建立只读对账工具，在已经导入 PostgreSQL 的历史数据与 002 来源文件之间逐条校验。工具不执行 `INSERT`、`UPDATE`、`DELETE` 或数据库回滚。

## 变更

- 新增 `scripts/verify-legacy-import.js`，比较历史答卷 ID、状态、次数、客观题/问答题/总分/通过线/通过状态。
- 比较每道题的题目快照、考生作答、自动与人工得分，兼容 002 首题缺失 ID 的稳定来源键。
- 新增单元测试和 `npm run verify:legacy-import` 命令。

## 数据安全与验证

工具仅输出数量和通过/失败结论；发生不一致时只报告答卷 ID、题号和字段名称，不输出题目、作答、答案、身份或数据库密码。

- `npm run check`：通过，15 项测试通过，敏感信息扫描通过。
- 临时 PostgreSQL 完整链路：2 条来源答卷、2 条数据库答卷、72 条逐题快照全部对账通过。
- 对账工具只执行 `SELECT`，不修改数据库。

## 风险与回滚

对账失败时应立即停止后续 API 改造和上线，保留现有数据库与来源备份用于分析。该工具不写入数据，因此无需数据库回滚。
