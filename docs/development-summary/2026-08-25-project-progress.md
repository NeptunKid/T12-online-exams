## 3. 已完成业务能力

### 考试、题库和题目

- 题目只归属题库，试卷从绑定题库选择题目；题库不保存试卷分值，分值属于试卷组卷关系。
- 支持单选、多选、判断、填空和简答；题干、选项均可有图片，题目可填写解析和结构化参考答案。
- 题库支持新建、编辑、复制、归档、恢复、软删除和满足引用条件后的永久删除；历史试卷、答卷、快照和审计不被级联破坏。
- 试卷支持新建、复制、版本化修订、绑定/切换题库、部分或全选题目、稳定排序、按题型批量设分、手动调整和一个保存按钮整体提交。
- 发布前如果题目、顺序或分值存在未保存修改，会提示保存或取消，不会清空题库或草稿；已删除试卷从列表隐藏，恢复只能依赖备份或数据库回滚。
- 历史答卷使用交卷时题目快照和评分依据，后续题库编辑不会静默改变历史成绩；考生端已通过/待考核分类和提交按钮恢复逻辑已修复。

### 导入、导出和备份

- `.t12backup` 是自包含格式，保存题库、试卷、组卷关系、分值、答题规则、授权、补考权限、解析和图片正文。
- 导入校验 manifest、关系、题序、分值、MIME、魔数、大小、整体 SHA-256 和逐图片 SHA-256；导入总是生成新对象并转为草稿，失败整体回滚。
- 自动备份支持 PostgreSQL 或受控文件系统目录、周期、保留数、运行记录、SHA-256 和下载；灾难恢复 `pg_dump -Fc` 与逻辑备份分离。

### 登录、组织和授权

- 钉钉/飞书 OAuth 双入口、统一内部用户、RBAC、系统管理员和阅卷权限已完成。
- 同名账号不会自动合并；系统管理员只能对唯一候选进行人工确认，事务迁移角色、授权、补考权限和答卷归属，保留 disabled 副本和审计。
- 试卷授权支持有效用户、已同步部门、全部有效用户和全部有效钉钉用户；部门授权要求目录中已同步且有效的部门。
- 钉钉/飞书通讯录同步支持部门树、人员分页、多部门关系和根部门回退；平台错误保留安全错误码/短消息，飞书空目录问题已在生产验收成功。

### 阅卷和通知

- 客观题自动评分，填空支持别名/顺序规则，简答由管理员阅卷；阅卷保存逐题分数并重算结果。
- `submission.created` 只通知有效管理员；`submission.graded` 同时通知考生和有效管理员，消息包含考生姓名、考试名、成绩/通过状态和站内链接，不发送答案或解析。
- Worker 使用 PostgreSQL 锁、幂等键、指数退避、processing 恢复、最大尝试和送达回执；管理员可查看脱敏状态并人工重发。
- 飞书和钉钉消息均已由用户配置并实测成功；旧历史 pending 任务仍须按事件/收件人核对后再决定是否处理，不能自动改写收件人。
