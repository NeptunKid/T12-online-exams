# 2026-08-11 题目图片附件上传

## 目标

管理员在新建或编辑题目时可直接上传题干图片，图片不依赖代码目录和手工部署，后续可随试卷/题库备份包一起导出。

## 实现

- 新增可回滚迁移 `0008_question_resources`，将图片本体和 MIME、字节数、SHA-256、创建人保存在 PostgreSQL。
- 只允许 JPEG、PNG 和 WebP；单张限制 5MB，拒绝 SVG、非法 Base64、MIME 伪装和超限内容。
- 以 SHA-256 去重；冲突时再核对正文、MIME 和大小，不静默复用异常数据。
- 上传仅对题库管理员开放，要求同源 JSON；图片读取要求有效登录会话，返回固定 MIME、`nosniff`、私有缓存和 ETag。
- 题目最多引用 5 张图片；题目保存前会确认上传资源真实存在。
- 管理员新建/编辑题目界面支持选择多图、预览、移除和上传中防误保存/切换。

## 数据边界

- 新题只进入题库，不自动加入任何试卷。
- 编辑题目仍递增题目及引用试卷版本并写审计，不改写 `submissions`、`submission_questions` 或已有成绩。
- 图片本体位于 PostgreSQL，`pg_dump -Fc` 会完整包含，为后续自包含导入导出奠定资源边界。

## 验证

- 完整 `npm run check`：174 项测试、语法检查和敏感信息扫描通过。
- 覆盖迁移/回滚、MIME 与 magic bytes、5MB 上限、Base64、去重与冲突、资源读取、题目引用验证、前端上传/预览/移除和移动端固定布局。
- 未连接真实 PostgreSQL 或浏览器选择本地图片做端到端验收。

## 风险与回滚

- 生产执行 `0008` 前必须在阿里云 Workbench 完成 `pg_dump -Fc`，迁移后检查数据库空间。
- 上传图片会增加 PostgreSQL 主库和备份体积；本步通过 5MB 单图上限、5 张/题和 SHA-256 去重控制增长，尚未增加系统级配额。
- 没有历史答卷引用上传图片时，down 会移除当前题目的上传 URL 并删除资源表。一旦历史快照已引用，down 会主动拒绝；应保留该迁移或恢复迁移前完整备份。
