# 2026-08-12 题目图片重复显示修复

## 问题与根因

- 考生答题页和管理员阅卷页中，数据库已经返回的当前题库图片，又被旧版 `exam_data.js` 兼容层重复追加。
- 两套路径名不同，但文件内容相同，所以仅比较 URL 不能消除重复。

## 修复

- 旧版兼容层按静态图片 SHA-256 识别相同内容，当前题库路径优先，仅补入内容不同的旧图片。
- 题库资源映射层也去除同一数组中的重复 URL。
- 选项图片只在同一标签内以当前数据为准，不会跨 A/B/C 等标签合并。
- 修复位于考生试卷与管理员阅卷共用的服务端出口，两个界面同时生效。
- 考生成绩详情的兼容层也改为答卷快照图片优先，避免旧图片覆盖历史快照。

## 数据安全与回滚

- 本步无数据库迁移，不修改题库、试卷、答卷、历史快照或图片文件。
- 回滚时恢复 `server.js` 和 `src/resources/question-resources.js` 中本次去重逻辑即可。

## 验证

- 聚焦回归：相同内容去重、不同内容保留、同源重复 URL 去重、选项标签隔离、考生/管理员共用出口。
- `npm run check`：248 项测试、语法检查和敏感信息扫描全部通过。
- `git diff --check`：通过。
- 本步不进行生产数据库写入。
