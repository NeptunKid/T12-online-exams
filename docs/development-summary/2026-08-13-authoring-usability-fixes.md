# 2026-08-13 题库与试卷编辑体验修复

## 完成内容

- 题库维护改为单个题库下拉框，下方展示题库状态、题目数、版本、关联试卷和说明，避免长名称溢出。
- 选择题、判断题、多选题改为单选/复选控件；判断题界面显示“正确/错误”，保存继续使用 A/B 兼容格式。
- 填空题支持多空规则：每行一个空，空内用 `|` 分隔允许答案；支持“必须按指定顺序”开关，默认开启；旧单空数组继续兼容。
- 新题和既有题目的每个选项支持上传、预览、替换和移除图片；图片 URL 仍必须是受控资源。
- 已发布试卷点击编辑只进入本地编辑态；首次真实保存才在事务内转为草稿并递增版本。取消编辑不发写请求；旧 `/revision` 路由改为只读兼容。
- 批量分值输入在保存后保留，不再重置为 1；分值重算总分和通过分。
- 多空填空在考生端按空渲染输入框并提交字符串数组；服务端 legacy 清洗和 PostgreSQL 判分均兼容。
