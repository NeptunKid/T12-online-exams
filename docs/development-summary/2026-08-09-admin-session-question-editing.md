# 管理员会话、题目显示与题库编辑

日期：2026-08-09  
分支：`feature/admin-question-editing`

## 需求范围

- 管理员后台在页面打开、恢复前台和会话过期时提前要求重新登录，避免保存阅卷结果时才发现会话失效。
- 将题干中的 `【】` 在试卷和答卷详情中显示为下划线，不修改数据库原题干。
- 允许考试管理员和系统管理员编辑已有题目的题干、选项、参考答案和解析并保存到 PostgreSQL。
- 本次不提供新增、删除题目、修改题型、修改分值或图片上传。

## 实现与兼容性

- 管理 API 的 `401` 会统一锁定后台；页面打开、`pageshow`、回到前台及每 60 秒心跳都会验证管理员权限。
- 新增 `GET /api/admin/questions` 与 `PUT /api/admin/questions/:id`，普通 `grader` 无题库维护权限。
- 题目保存使用 PostgreSQL 事务、乐观版本校验和审计日志；保留既有受控图片资源，并递增题目及引用考试的版本号。
- 考生交卷携带试卷版本；管理员修改题目后，已打开的旧试卷会被拒绝提交并提示刷新，避免按不同版本静默判分。
- 历史答卷仍读取 `submission_questions.snapshot_json`，不更新、不覆盖历史题目和成绩。

## 数据库迁移

无。复用现有 `questions`、`exams`、`exam_questions` 和 `audit_logs` 表。

## 测试

- `npm run check:syntax`
- `npm test`
- `npm run check:secrets`

覆盖题目字段校验、选项图片保留、版本冲突、考试版本冲突、RBAC 权限和占位符安全渲染。

## 风险与回滚

- 当前会话仍存于 Node 进程内存，服务重启后管理员和考生仍需重新登录。
- 题目编辑会立即成为引用考试的下一版本；正在作答的旧页面需要刷新后重新开始。
- 回滚代码时部署上一版 `main` 并重启 `t12-exams`；本次无数据库结构回滚。若需撤销已保存的题目内容，应依据 `audit_logs` 审计记录人工复核后再通过编辑界面改回，不直接修改历史答卷。
