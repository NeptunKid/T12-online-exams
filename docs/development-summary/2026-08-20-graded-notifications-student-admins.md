# 成绩通知同时发送给考生和管理员

日期：2026-08-20

## 修改内容

- `submission.created` 保持只通知有效阅卷人、考试管理员和系统管理员。
- `submission.graded` 合并答卷人的有效平台身份与所有有效管理员身份。
- 同一平台身份同时属于考生和管理员时去重，保证一个事件只创建一条任务。
- 成绩消息新增考生姓名，仍不包含答案、解析或其他作答内容。

## 数据与部署边界

- 无新数据库迁移，无历史通知回填；已有成绩事件不会自动重新创建管理员任务。
- 未实现钉钉发送时，钉钉任务仍保留为 `pending`；飞书 Worker 只处理飞书通道。
