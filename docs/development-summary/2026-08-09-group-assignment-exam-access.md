# 全员授权考试访问修复

日期：2026-08-09
分支：`fix/group-assignment-exam-access`

## 问题与修复

- 考试列表查询使用 `$1` 传入钉钉身份，因此新考生能看到清洁卫生考试。
- 按考试 ID 读取题目时，授权 SQL 有两处身份条件，原实现只将第一处 `$1` 替换为 `$2`；全员组授权路径错误地把考试 ID 当成钉钉身份，返回“未发布该考试”。
- 修复后授权 SQL 由函数显式接收占位符，详情查询的个人授权和全员组授权均使用 `$2`。

## 影响与回滚

- 数据库迁移：无。
- 答卷、题库、考试状态和授权数据：不修改。
- 验证：`npm run check`，并由新考生从首页进入清洁卫生考试。
- 回滚：revert 本 PR 并重启 `t12-exams`。
