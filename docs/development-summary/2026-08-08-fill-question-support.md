# 开发总结：填空题题型与自动判分

日期：2026-08-08

## 范围

- CSV 题库预览支持 `fill` 题型；填空题不填写选项，答案列可用 `|` 分隔多个可接受答案。
- PostgreSQL 新增 `0003_fill_question_type` 迁移，允许 `questions.type = 'fill'`，并提供同名回滚脚本。
- Node.js 旧版兼容评分和 PostgreSQL 评分均支持填空题自动判分：忽略首尾空格、不区分大小写。
- 考生端显示填空文本框；阅卷后台将填空题作为客观题展示，仍可逐题人工覆盖得分。

## 风险与回滚

- 风险：OCR 可能误识别中文题干、选项或答案，必须在导入前审阅 CSV 预览。
- 应用回滚：回退本次代码提交。
- 数据库回滚：在没有后续迁移时执行 `npm run migrate -- --rollback 0003_fill_question_type --allow-destructive`；该回滚只恢复题型约束，不删除题目记录。
