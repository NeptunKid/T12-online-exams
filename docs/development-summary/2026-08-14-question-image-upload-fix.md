# 2026-08-14 新题图片上传状态修复

## 问题

生产验收新增题目时，上传题干或选项图片会重绘表单，但重绘前未保存 DOM 中尚未提交的题干和选项内容，导致内容清空；同时上传完成前重绘会读取 busy 状态，使后续上传控件和保存按钮保持禁用。

## 修复

- 新题上传题干图片或选项图片前，先将当前表单同步回 `newQuestionDraft`。
- 题干图片和选项图片上传成功或失败后，先清除 `questionImageUploadBusy`，再重绘编辑器。
- 保留上传结果、已有文字、答案勾选和其他图片，允许继续上传并保存。

## 验证与边界

- 新增图片上传 UI 回归测试。
- 无数据库迁移、无生产数据写入、未修改历史答卷。
- 部署前仍需创建 PostgreSQL `pg_dump -Fc`；部署后由用户验收题干图片、多个选项图片和保存题目。
- 回滚方式：恢复本次代码提交并重启服务。
