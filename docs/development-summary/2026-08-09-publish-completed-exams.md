# 已完成试卷发布与学员授权

日期：2026-08-09
分支：`feature/publish-completed-exams`

## 需求与范围

- 将萃取原理、消防基础、IT 基础三份已完成试卷发布到生产数据库。
- 为所有已登录且状态为 `active` 的钉钉用户批量建立考试授权。
- 保留原有 `--union-id` 单人授权方式，不修改历史答卷或数据库表结构。

## 实现

- 导入脚本新增 `--all-active-dingtalk-users`，批量授权使用唯一约束幂等写入。
- 脚本在连接 PostgreSQL 前读取 `T12_ENV_FILE`，适配生产环境的 `/etc/t12-online-exams/t12-online-exams.env`。
- 批量授权时如找不到有效钉钉用户，会在事务内报错并回滚，避免出现“考试已发布但任何人都看不到”。

## 验证与回滚

- 质量门：`npm run check`。
- 生产导入前必须执行 PostgreSQL `pg_dump -Fc` 备份。
- 导入本身使用单一数据库事务；任一题库或授权校验失败时不保留部分写入。
- 代码回滚使用 PR 的 revert；数据回滚使用导入前备份，不直接删除历史答卷。

## 风险

- 批量授权只覆盖执行导入时已登录的有效钉钉用户；之后首次登录的新员工需要另行授权或重复执行本幂等导入命令。
- 飞书用户尚未纳入本次授权，待 Phase 4 统一身份与分配模型完成后处理。
