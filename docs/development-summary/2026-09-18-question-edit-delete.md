# 2026-09-18 题目完整编辑与删除

## 目标

让题库维护支持对单题进行完整修改和删除，同时保持历史答卷快照与已生效试卷的可追溯性。

## 本轮实现

- 题目编辑器支持所有题型切换；单选题和多选题可互相切换，选项可增加到 10 个或删除到至少 2 个，并自动整理 A-J 编号和参考答案。
- 题目编辑器支持从题库删除所有题型。删除采用软删除，将题目状态改为 `archived`，不物理删除题目资源或历史答卷。
- 删除被 `scheduled`、`published` 或 `paused` 试卷引用的题目时，服务端先返回引用列表并要求确认。确认后，原生效试卷保留历史版本，将该题分值置为 0 并递增版本，同时生成排除该题的新 `draft` 试卷，复制原试卷参数、题库和授权。
- 删除和生成新试卷在同一数据库事务内完成，任一步失败都会回滚；历史答卷不被改写。
- 前端在切换题型、增加或删除选项前同步未保存的题干、选项、答案、解析和图片草稿，避免操作顺序造成编辑内容丢失。
- 更新题目的审计记录现在包含修改前的题型。
