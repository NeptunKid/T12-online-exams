# PostgreSQL 考试交卷 API

日期：2026-08-08

## 本次范围

- 新增 `POST /api/exams/:examId/submissions`，只接受当前钉钉身份已获个人授权的已发布考试。
- 交卷、客观题评分和逐题快照在同一个 PostgreSQL 事务中完成。
- 单选、判断、多选支持全对、漏选半分和错选零分；问答题保留 `pending`，等待后续阅卷流程。
- 响应只返回答卷 ID、状态、客观题分数和次数，不返回标准答案或解析。
- 保留旧 JSON 交卷接口，确保历史答卷和旧前端兼容。
