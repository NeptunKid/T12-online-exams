# 归档题库永久删除误判修复

日期：2026-08-20

## 问题

归档题库在永久删除时，系统会把已经归档（已删除）的试卷也计入引用数量，导致题库实际没有被有效试卷使用时仍提示“该题库仍被试卷引用”。

## 修改

- 永久删除引用检查只统计 `exams.status <> 'archived'` 的试卷。
- 题库维护列表和题库详情中的试卷数量同步排除已归档试卷，避免界面显示误导。
- 删除前清理已归档试卷的 `exam_questions` 关系并将 `exams.question_bank_id` 置空，避免数据库外键错误。
- 保留题目、试卷、答卷和审计的现有事务与数据保护规则。

## 验证

- 题库生命周期回归测试通过。
- 语法检查通过。
- 无数据库迁移、无生产写入、未执行生产部署。

## 风险与回滚

- 仅改变引用计数和永久删除前置判断；有效试卷仍会阻止永久删除。
- 若部署后出现异常，回滚本次代码提交并重启服务；生产数据不需要回滚。
