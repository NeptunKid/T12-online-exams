核心业务闭环已完成并在生产运行：钉钉/飞书登录、管理员权限、题库和试卷维护、组卷发布、答卷与阅卷、成绩通知、备份恢复基础和组织通讯录同步均已实现。最新生产版本由用户确认是 `c80cb83`，飞书通讯录同步已验收成功。

本机当前代码质量门为 `npm test` 354/354 通过，语法检查、敏感信息扫描和 `git diff --check` 通过。生产数据库继续使用 PostgreSQL，应用通过 Caddy + HTTPS 对外提供服务。

## 已完成模块

### 工程、安全与部署

- GitHub 分支、PR、GitHub Actions 质量门和生产部署 runbook 已建立。
- 生产架构稳定为 Cloudflare/Caddy -> Node.js 127.0.0.1:3001 -> PostgreSQL 127.0.0.1:5432。
- 每次部署前使用 `pg_dump -Fc`，记录备份路径、大小和 SHA-256；Git/npm 使用 `codexdeploy`，系统操作使用 `sudo`。
- OAuth、消息和数据库凭证只从环境变量或部署 Secret 读取。

### 考试、题库与试卷

- PostgreSQL 多考试模型、考试状态、版本和历史答卷题目快照已完成。
- 题库支持新建、编辑、复制、归档、恢复、删除和图片资源管理。
- 题目支持单选、多选、判断、填空、简答，包含题干/选项图片、参考答案和解析。
- 试卷从题库选题；支持全选、部分选题、排序、题型分组批量设分、手动调整和单按钮整体保存。
- 已发布试卷可创建新修订；未保存修改在发布前提示保存或取消，不会清空草稿。
- 已删除试卷从列表隐藏；历史答卷和快照不受题库/试卷后续编辑影响。

### 导入、导出与备份

- `.t12backup` 自包含备份包保存试卷、题库、组卷关系、授权、答案解析和图片资源。
- 导入会校验格式、关系、MIME、魔数、大小和 SHA-256，并以新对象、草稿状态导入，失败整体回滚。
- 自动备份支持 PostgreSQL 或受控文件系统目录、周期、保留数、运行记录和下载。
- PostgreSQL 灾难恢复备份与逻辑备份分离，生产恢复前要求先在隔离环境验证。

### 登录、组织和授权

- 钉钉与飞书 OAuth 登录、管理员双入口、RBAC、同名账号人工合并已完成。
- 试卷授权支持用户、部门、全部有效用户和全部有效钉钉用户。
- 钉钉/飞书组织通讯录同步已完成，部门和人员可用于授权；飞书部门树为空时会查询根部门 `department_id=0`，当前已生产验收成功。

### 通知与阅卷

- Outbox 事件、幂等、重试、领取恢复、送达状态和管理员通知管理已完成。
- 飞书和钉钉工作通知 transport 已实现。
- 交卷提醒只发管理员；成绩通知包含考生姓名，并同时发给考生和有效管理员。
