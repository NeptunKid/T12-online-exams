# 生产考试流程修复

日期：2026-08-09
分支：`fix/production-exam-workflow`

## 需求与变更

- 清洁卫生入职培训考试时长修正为 45 分钟，四份已开放考试增加全员组授权。
- 考生权限查询同时支持个人授权和 `all-active-dingtalk-users` 组授权，后续首次登录的有效员工也可见。
- 管理员答卷列表、详情、阅卷保存和补考授权切换到 PostgreSQL，阅卷写入使用事务。
- 纯客观题答卷也先进入待阅卷；迁移仅将三份新考试中没有阅卷人和阅卷时间的自动完成记录恢复为待阅卷。
- 已批阅详情兼容历史 `text` 题干与对象选项，展示题干、图片、选项、作答、标准答案、解析和得分。
- 新答卷快照完整保存标准答案；待阅卷考生接口仍不返回标准答案和解析。

## 数据与兼容性

- 新增迁移：`0004_production_exam_workflow`。
- 不删除、覆盖或重算历史答卷；题干兼容在读取时完成。
- 迁移回滚会删除本次全员组授权并将清洁卫生时长恢复为迁移前的 30 秒；生产优先使用迁移前 `pg_dump` 备份回滚。

## 验证、风险与回滚

- 质量门：`npm run check`。
- 风险：后台答卷数据源切换为 PostgreSQL，部署前必须确认历史答卷已完成迁移对账。
- 回滚：revert PR，恢复迁移前数据库备份，然后重启 `t12-exams`。
