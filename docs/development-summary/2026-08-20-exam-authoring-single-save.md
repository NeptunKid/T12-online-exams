# 试卷组卷统一保存与题型分值分组

日期：2026-08-20

## 修改内容

- 新增 `PATCH /api/admin/exams/:examId/authoring` 整体保存接口，在一个 PostgreSQL 事务中保存试卷参数、绑定题库、选题、题目顺序和逐题分值，并统一重算总分、通过分和版本审计。
- 组卷页面移除单题“保存分值”和独立“保存选题”按钮；选择、排序、手动分值和参数修改均先保存在本地草稿，统一由“保存全部修改”提交。
- 试题按单选、多选、填空、判断、问答分类展示；每类提供独立的批量分值输入，批量应用后仍可继续逐题手动调整。
- 更换题库也改为本地选择并在整体保存时提交，确认后自动清空旧选题和分值；历史答卷不受影响。
- 更新管理员脚本缓存版本，避免生产浏览器继续使用旧组卷页面。

## 风险与回滚

- 本次无数据库结构变化；旧的分步组卷 API 保留兼容，但新页面只使用整体保存接口。
- 发布前仍需按生产部署手册创建 PostgreSQL 备份。代码异常时回滚合并提交并重启服务即可；已提交的组卷数据由事务和备份保护。
