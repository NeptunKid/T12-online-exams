# 2026-08-14 试卷题库生命周期与学员工作台修复

## 完成内容

- 试卷更换绑定题库时，在同一数据库事务中自动清空旧选题和分值、绑定新题库、重算总分及通过分、递增版本并记录审计；不再要求管理员先手动清空。
- 题库和试卷提供用户可理解的删除与恢复操作。试卷删除采用软删除：状态改为 `archived`，数据仍保留并可恢复；已归档且未被任何试卷引用的题库支持管理员确认后永久删除，删除题库及其题目并写审计记录，被试卷引用时拒绝永久删除。
- 试卷和题库的软删除不会物理删除题目、组卷关系、答卷、逐题答卷、历史快照或成绩；题库永久删除仅允许无试卷引用的归档题库，因此不会触及任何历史答卷或组卷关系。
- 学员工作台将“待考核项目”改为“待考核科目”；任何已有已批阅且通过答卷的考试归入“已通过”，不再显示开始考核按钮。重新开始一场考试时会恢复“提交试卷”按钮，提交网络失败也会恢复按钮，避免上一场答卷的禁用状态泄漏。
- 新试卷、编辑后试卷和草稿试卷的操作按钮统一显示“发布”。
- 更新管理员和学员页面静态资源版本，避免部署后使用旧缓存。
