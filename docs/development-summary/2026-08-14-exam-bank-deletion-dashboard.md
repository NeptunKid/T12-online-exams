# 2026-08-14 试卷题库生命周期与学员工作台修复

## 完成内容

- 试卷更换绑定题库时，在同一数据库事务中自动清空旧选题和分值、绑定新题库、重算总分及通过分、递增版本并记录审计；不再要求管理员先手动清空。
- 题库和试卷提供用户可理解的删除与恢复操作。删除采用软删除：试卷和题库状态改为 `archived`，数据仍保留；试卷恢复后进入草稿，确认后才能重新发布。
- 软删除不会物理删除题目、组卷关系、答卷、逐题答卷、历史快照或成绩。
- 学员工作台将“待考核项目”改为“待考核科目”；任何已有已批阅且通过答卷的考试归入“已通过”，不再显示开始考核按钮。
- 更新管理员和学员页面静态资源版本，避免部署后使用旧缓存。

## 验证边界

- 覆盖换绑题库原子清空、总分/通过分重算、版本和审计、删除/恢复乐观锁、历史数据不写入、管理员按钮与学员分类。
- 无数据库迁移；使用现有 `archived` 状态实现可恢复删除。
- 未连接或写入生产数据库，未执行 GitHub 网络操作，未使用浏览器控制验收。

## 部署与回滚

- 合并后按 `docs/production-deployment-runbook.md` 执行完整备份、部署、迁移、重启和健康检查。
- 功能验收由用户执行：换绑题库、删除/恢复题库、删除/恢复试卷、学员已通过分类。
- 代码问题可部署上一份已验证提交；若已发生管理员写操作，保留审计记录并优先使用恢复按钮，不直接修改数据库或历史答卷。
