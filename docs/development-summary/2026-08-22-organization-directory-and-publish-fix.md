# 2026-08-22 组织目录同步与发布前保存

## 需求

- 部门授权不能继续使用自由文本；管理员需要先同步钉钉或飞书通讯录，再从已同步的有效部门中选择。
- 同步后管理员用户列表应包含数据库中全部有效人员，试卷授权部门应通过稳定的目录 ID 关联。
- 试卷在题目、排序或分值尚未保存时点击“发布”，不能丢失当前草稿；应先询问是否保存，取消时保留当前编辑内容。

## 实现

- 新增可回滚迁移 `0012_organization_directory`，建立 `organization_departments` 和 `user_departments`，为部门、人员和多部门关系提供稳定主键。
- 新增钉钉/飞书通讯录同步适配器：钉钉读取部门树和人员分页，飞书读取部门及人员分页；凭证只从环境变量读取。
- 新增组织目录仓储和管理员 API：`GET /api/admin/organization/directory`、`POST /api/admin/organization/sync`。
- 管理员页增加通讯录同步按钮、同步统计和部门下拉框；移除部门自由文本输入。新增部门授权在服务端事务内再次确认部门存在且为 active，不能通过接口写入任意名称。
- 试卷列表、详情、学员授权查询和交卷授权判断支持 `user_departments`；旧部门文本授权保留兼容读取，但新授权必须使用同步目录 ID。
- 发布前检测未保存的参数、题目、排序和分值修改；确认后先整体保存，再使用最新版本发布；取消只退出发布流程，不清空草稿。
- 后台 `admin.js` 缓存版本更新为 `20260822-2`。
