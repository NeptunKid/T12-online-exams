# 题库分类、答案排版与空白占位符

日期：2026-08-09  
分支：`fix/question-bank-layout-placeholders`

## 需求与变更

- 题库维护入口先选择试卷，再展示、搜索该试卷引用的题目，不再混合展示全部题目。
- 选择题的当前参考答案直接在选项编辑区高亮，参考答案统一在一个文本框内修改；多选答案支持 `A|B|D` 格式。
- `【】`、`「」`、`[]` 及其中只含空白字符的形式，显示为带下划线格式的连续空白字符。
- 括号内含任何非空白文字时保留原文，不进行转换。

## 数据与兼容性

- 无数据库迁移，不修改题库或答卷数据。
- 同一道题若被多份试卷引用，会出现在每个对应分类中；修改仍更新同一题目，并沿用既有事务、审计、版本递增和历史快照保护。

## 测试

- `npm run check`
- 70 项测试通过，包含试卷分类、搜索、多选答案解析、三种占位符、非空括号保护和下划线样式约束。
- 语法检查和敏感信息扫描通过。

## 风险与回滚

- 回滚时部署上一版 `main` 并重启 `t12-exams`；无数据库回滚操作。
- 本次只改页面筛选和显示，生产部署无需执行迁移或 `npm ci`。
