# 2026-08-22 考试授权管理

## 目标

把考试可见范围纳入现有试卷组卷页面，避免授权只能靠数据库脚本维护。题库和试卷仍保持独立：授权只属于试卷，不改变题库题目关系。

## 已完成

- 复用现有 `exam_assignments` 表，支持用户、部门和两个内置群组：
  - `all-active-users`：全部有效用户；
  - `all-active-dingtalk-users`：全部有效钉钉身份用户。
- 管理员组卷页面显示当前授权，可添加或移除授权。
- 用户授权使用受控的有效用户目录；部门授权使用部门名称；不允许自定义群组标识。
- 新增和移除授权都通过现有试卷事务、版本乐观锁和审计日志完成。
- 每份试卷至少保留一条授权，避免保存后试卷对所有考生不可见。
- 同一试卷、类型和对象重复授权采用幂等更新时间范围，不产生重复记录。
- 学员试卷列表、试卷详情、交卷和工作台查询均支持部门授权，并要求用户及身份处于有效状态。
- 管理后台脚本缓存版本更新为 `20260822-1`，避免生产浏览器继续使用旧授权界面。

## 变更范围

- `src/db/exam-authoring-repository.js`：授权校验、查询、新增、移除和审计事务。
- `src/http/admin-exam-authoring-handler.js`：用户目录、授权读取、新增和移除 API。
- `src/db/user-repository.js`：返回脱敏的有效用户目录字段。
- `src/db/exam-repository.js`：三条考生访问路径增加部门授权判断。
- `public/admin.js`、`public/styles.css`、`public/admin.html`：组卷页授权管理和资源缓存版本。
- 测试覆盖 API/UI、部门 SQL、版本冲突、无效用户回滚、重复授权、最后一条授权保护和记录归属校验。

## 部署与回滚

合并后必须在阿里云 Workbench 按 `docs/production-deployment-runbook.md` 操作，先执行 PostgreSQL `pg_dump -Fc`，再拉取代码、安装依赖、执行现有迁移计划并重启服务。虽然本轮没有新迁移，备份仍是部署前置条件。

部署后请由用户验收：用户授权、部门授权、内置群组授权、移除最后一条授权的提示、版本冲突提示，以及部门成员登录后能看到并提交对应试卷。

代码异常时回滚合并 PR 或恢复上一已验收提交并重启；本轮没有新增数据库结构，不需要执行 down 迁移。不要通过手工删除授权记录恢复业务状态。
