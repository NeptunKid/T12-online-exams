# 试卷与题库可移植备份

日期：2026-08-11

## 本步完成

- 管理员新增“备份”入口，可分别选择试卷或题库导出 `.t12backup`。
- 备份包为单文件 ZIP，内含完整结构化数据及 Base64 图片原始正文，不需要再次上传资源。
- 图片同时校验 MIME、magic bytes、大小和 SHA-256，完整 payload 另有稳定 SHA-256。
- 一键导入始终创建新的题库、题目和试卷 ID；试卷固定为草稿，不覆盖现有记录。
- 试卷分值只保存在组卷关系，题库题目不携带分值。
- 导入事务任一步失败即整体回滚，相同图片可按 SHA-256 安全复用。
- 上传接口限制同源 multipart、单文件和 200MB 包体；ZIP 解析拒绝路径穿越、CRC 篡改和压缩炸弹。

## 修改范围
