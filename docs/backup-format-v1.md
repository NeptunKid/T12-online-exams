# T12 试卷与题库备份格式 v1

## 文件容器

- 文件扩展名：`.t12backup`
- 容器：标准 ZIP
- ZIP 内必须且只能包含 `backup.json`
- 格式标识：`t12-online-exams-backup`
- 格式版本：`1`

导入器拒绝分卷、加密、ZIP64、路径穿越、重复文件、未知压缩算法、CRC 错误以及超过限制的包体。当前上传包最大 200MB，图片正文合计最大 100MB，单张图片最大 5MB；导出端使用相同限制，避免生成无法回导的文件。

## backup.json

顶层字段固定为：

```json
{
  "manifest": {},
  "questionBanks": [],
  "questions": [],
  "exams": [],
  "examQuestions": [],
  "assignments": [],
  "retakePermissions": [],
  "resources": []
}
```

`manifest` 保存格式、版本、类型、导出时间、各数组数量和完整 payload 的 SHA-256。`resources` 为每张图片保存资源标识、MIME、字节数、SHA-256 和 Base64 原始正文，因此不依赖原服务器文件或人工补传图片。

题库题目不保存分值。试卷中的题目顺序和分值只保存在 `examQuestions`。题型、题干、题干图片、选项及选项图片、参考答案、解析、题目状态、试卷时长、总分、通过分、通过比例、作答规则、题库绑定、考试分配和补考权限均随相应备份包保存。

试卷/题库备份不包含用户档案、OAuth 身份、答卷、答卷快照、阅卷结果或审计历史。这些运行数据继续由 PostgreSQL 的 `pg_dump -Fc` 负责灾难恢复，避免可移植业务包携带答卷和身份敏感信息。

## 导入语义

- 导入前校验格式版本、字段白名单、数量、关系、题序、分值合计、整体 SHA-256、图片 SHA-256、MIME、magic bytes 和大小。
- 题库、题目、试卷及关系全部生成新 ID，不覆盖已有记录。
- 导入的试卷固定创建为 `draft`，避免恢复后自动开放考试。
- 相同 SHA-256 的数据库图片复用已有正文，但会复核 MIME、大小和二进制内容。
- 个人考试分配或补考权限引用的用户必须在目标系统中仍为有效用户，否则整包拒绝导入，避免产生悬空权限。
- 全部数据库写入位于同一个事务中，任何失败都会整体回滚。
- 成功导入会写入 `import_backup` 审计记录。

## 版本演进

新增或改变字段语义时必须递增 `formatVersion`，并为旧版本保留明确的迁移器；不得静默猜测未知字段。定期自动备份、保留周期及外部存储适配器属于后续独立步骤，不改变 v1 可移植包格式。
