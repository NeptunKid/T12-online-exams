# 在线考试后台追踪系统 - 钉钉飞书接入版

这是从 `002_考试后台追踪系统_钉钉登录版` 导入的开发基线。当前仅保留钉钉版历史行为，飞书登录、数据库和多考试模型将在后续 Sprint 中逐步加入。003 使用独立数据目录，不会读取或修改 `001`、`002` 的生产答卷。

## 运行前配置

在钉钉开放平台创建企业内部应用，启用钉钉登录能力，并申请读取当前登录用户基本资料所需权限。将下列地址登记为应用的 OAuth 回调地址：

```text
http://127.0.0.1:3001/auth/dingtalk/callback
```

正式部署时请替换为实际的 HTTPS 域名回调地址，例如：

```text
https://exam.example.com/auth/dingtalk/callback
```

配置应用的 Client ID、Client Secret。项目根目录的 `.env` 会在每次启动时自动读取，请在其中填写这两个值和阅卷人 `unionId` 白名单。多位阅卷人的 `unionId` 用英文逗号分隔。

```bash
cd $HOME/Documents/Codex/003_考试后台追踪系统_钉钉飞书接入版
npm start
```

本地试运行时，`DINGTALK_REDIRECT_URI` 必须与钉钉开放平台登记的地址完全一致。若钉钉不允许回调到本机地址，请使用可访问的测试 HTTPS 域名或内网穿透地址。

## 访问地址

默认端口为 `3001`：

- 考生考试页：`http://127.0.0.1:3001/`
- 阅卷后台：`http://127.0.0.1:3001/admin`

启动后未配置钉钉环境变量时，页面会明确显示未配置状态；不会回退到账号密码登录，也不会允许匿名提交。

## 数据与安全

- 答卷保存于独立的 `data/submissions.json`，稳定版数据不会被读取或修改。
- 客观题由服务端自动评分；考生提交后只看到“等待阅卷中”和客观题得分。
- 考生登录后进入个人工作台，可查看待学习与待考核项目、每一次考试记录；已完成阅卷的答卷可查看逐题结果、成绩、通过状态和阅卷批注。
- 问答题、总分、通过状态、阅卷人和备注由具有白名单权限的钉钉账号逐份保存。
- 阅卷人可逐题调整客观题分数，错题会突出显示并可一键筛选；也可为每份答卷单独设置通过线，并在必要时为考生额外开放一次补考。
- 会话只保存在服务进程内存中，重启服务后用户需要重新钉钉登录。
- `Client Secret` 保存在仅限本机的 `.env` 文件中；该文件已被 `.gitignore` 忽略，不要发送给他人或提交到版本控制记录。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `server.js` | 钉钉 OAuth、会话、答卷保存、自动评分、个人记录与阅卷接口 |
| `public/exam.html` / `public/exam.js` | 钉钉登录后的考生工作台、考试页与个人阅卷结果页 |
| `public/admin.html` / `public/admin.js` | 钉钉登录后的阅卷后台 |
| `data/submissions.json` | 003 开发环境答卷（生产数据不会自动迁移） |
| `public/exam_data.js` | 服务端读取的完整题库与标准答案 |
